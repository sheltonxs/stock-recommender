# A股智选 - 产品需求文档 (PRD)

> 版本: v2.0 | 日期: 2026-02-20 | 状态: 原型已实现

---

## 1. 产品概述

### 1.1 产品定位

**A股智选** 是一款面向个人投资者的A股每日推荐系统。系统在盘后自动采集市场数据，通过多因子规则引擎进行综合评分，每日生成100只推荐股票（覆盖26个行业）按分档展示，并通过可视化看板呈现。

### 1.2 核心价值

- 盘后自动化分析，省去人工盯盘和筛选的时间
- 多维度量化评分，减少情绪化决策
- 丰富的技术指标可视化，辅助投资判断

### 1.3 约束条件

| 约束 | 说明 |
|------|------|
| 用户规模 | 个人自用，单用户 |
| 数据源 | 纯免费（AKShare + 网页爬虫） |
| 数据时效 | 盘后分析（T+0），非实时行情 |
| AI方案 | 确定性规则引擎，无ML/LLM依赖 |
| 部署 | Docker容器，阿里云ECS |
| 预算 | 仅服务器费用（约50-100元/月） |

## 4. 数据分析模块

### 4.1 基本面分析引擎

**总分: 100分 = 估值(30) + 盈利能力(30) + 成长性(20) + 财务健康(20)**

#### 4.1.1 估值分析 (30分)

| 指标 | 评分规则 | 分值 |
|------|---------|------|
| PE(TTM) | <行业均值50%: +12 / <行业均值: +8 / 1-2倍均值: +4 / >2倍: 0 | 0-12 |
| PB | <1: +10 / 1-2: +7 / 2-5: +3 / >5: 0 | 0-10 |
| PEG | <0.5: +8 / 0.5-1: +6 / 1-1.5: +3 / >1.5: 0 | 0-8 |

#### 4.1.2 盈利能力 (30分)

| 指标 | 评分规则 | 分值 |
|------|---------|------|
| ROE | ≥20%: +12 / ≥15%: +9 / ≥10%: +5 / <10%: +2 | 0-12 |
| ROE连续3年≥15% | 额外加分 | +3 |
| 毛利率 | >行业均值20%: +8 / >均值: +5 / <均值: +2 | 0-8 |
| 净利率趋势 | 连续上升: +7 / 持平: +4 / 下降: +1 | 0-7 |

#### 4.1.3 成长性 (20分)

| 指标 | 评分规则 | 分值 |
|------|---------|------|
| 营收增速(YoY) | >30%: +8 / >20%: +6 / >10%: +3 / <10%: +1 | 0-8 |
| 净利润增速 | >40%: +7 / >25%: +5 / >10%: +3 / <10%: +1 | 0-7 |
| 连续增长季度数 | ≥4季: +5 / ≥2季: +3 / 其他: 0 | 0-5 |

#### 4.1.4 财务健康 (20分)

| 指标 | 评分规则 | 分值 |
|------|---------|------|
| 资产负债率 | <40%: +7 / <60%: +5 / <80%: +2 / ≥80%: 0 | 0-7 |
| 经营性现金流 | >净利润: +7 / >0: +4 / <0: 0 | 0-7 |
| 流动比率 | >2: +6 / >1.5: +4 / >1: +2 / <1: 0 | 0-6 |

### 4.5 多因子综合评分

```
最终得分 = 技术面(30%) + 基本面(25%) + 资金面(25%) + 市场情绪(20%)
```

**权重说明：**

| 因子 | 权重 | 理由 |
|------|------|------|
| 技术面 | 30% | 短期交易信号最直接的指引 |
| 基本面 | 25% | 安全边际，降低踩雷概率 |
| 资金面 | 25% | 真金白银是最真实的市场投票 |
| 市场情绪 | 20% | 热点催化，但波动大权重稍低 |

### 4.6 过滤规则（硬性排除）

在评分前先排除以下股票：

| 规则 | 说明 |
|------|------|
| ST/*ST | 退市风险股全部排除 |
| 上市不足60日 | 新股波动大，数据不足 |
| 当日换手率>20% | 异常波动，游资炒作嫌疑 |
| 停牌中 | 无法交易 |
| 市值<20亿 | 排除壳股和微盘股 |
| 涨跌幅>9.5% | 已涨停/跌停，无法买入 |

### 5.2 主看板页面

**布局: 暗色主题仪表盘**

组件从上到下依次排列：

1. **市场指数卡片行** (4列): 上证指数、深证成指、创业板指、北向资金
2. **双图行** (2列): 板块热力图 (Treemap) + 资金流向桑基图 (Sankey)
3. **情绪行** (2列): 涨跌分布环形图 (Pie/Ring) + 市场情绪仪表盘 (Gauge)
4. **推荐区**: 100只股票分档展示，含筛选/排序工具栏

**推荐区分档规则**:

| 档位 | 排名 | 展示方式 | 特征 |
|------|------|---------|------|
| Tier 1 | 1-10 | 完整表格 + 核心信号列 | 金色标签, 所有列可见 |
| Tier 2 | 11-30 | 标准表格, 无信号列 | 蓝色标签 |
| Tier 3 | 31-100 | 紧凑表格 + 分页 (20条/页) | 灰色标签 |

**筛选工具栏**:
- 行业下拉 (26个行业)
- 风险等级下拉 (低/中/高)
- 最低综合分 (数字输入)
- 排序方式 (综合分、涨幅、技术分、基本面)
- 结果计数器 (实时显示筛选结果数量)

所有筛选/排序在客户端 JavaScript 完成, 数据通过 `all_recommendations_json` 一次性传递。

**全局搜索栏**: 导航栏内嵌搜索框, 支持按股票代码/名称模糊匹配, 调用 `/api/search?q=` 接口, 结果以下拉列表形式实时展示。

### 6.2 异常处理

| 异常场景 | 处理策略 |
|---------|---------|
| AKShare接口超时 | 重试3次，间隔30秒 |
| AKShare接口返回空 | 使用最近一次缓存数据 |
| 数据库写入失败 | 事务回滚 + 日志告警 |
| 非交易日触发 | 检测交易日历，自动跳过 |
| 采集数据不完整 | 标记为"部分数据"，降低评分置信度 |

## 10. 风险提示

### 10.1 合规要求

- 系统界面底部固定显示：**"投资有风险，入市需谨慎。本系统仅供学习参考，不构成任何投资建议。"**
- 推荐结果页增加风险等级标识（低/中/高）
- 历史胜率统计仅供参考，过往表现不代表未来收益

### 10.2 技术风险

| 风险 | 缓解措施 |
|------|---------|
| AKShare接口变更 | 封装数据层，接口隔离 |
| 免费接口限频 | 添加请求间隔，错峰采集 |
| 数据质量问题 | 数据清洗 + 异常值检测 |
| SQLite并发限制 | 单用户场景无影响 |
